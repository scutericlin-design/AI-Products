今天怎么用这一套系统

Daily routine
1. 更新股票池

去“系统股票池”点更新，系统从全 A 股里筛出最多 30 只强势候选。

2. 看推荐原因

先看评分、动作、风险标记，不要只看涨幅或排名。

3. 对照持仓

去“个人持股”看哪些要降仓，避免新买和旧仓风险叠加。

4. 做人工复核

检查公告、涨跌停、成交额、行业拥挤度，确认不是单日情绪。

5. 形成计划

只输出明天的观察、加仓、减仓清单；不自动下单。

你看到的字段怎么理解
评分系统对强势程度、成交活跃度、日内位置和风险惩罚后的综合排序。
动作buy 代表进入核心候选；watch 代表只观察；avoid 代表暂不碰。
建议仓位不是必须买多少，而是这只股票在策略里允许暴露的上限。
风险标记告诉你为什么不能直接买，例如波动过高、收盘弱、成交不足。
理由把模型字段翻译成人话，方便你快速判断是否值得继续研究。

你需要亲自确认什么

No autopilot
是不是涨停买不到如果封单很强，推荐也可能无法成交，不能按收盘价幻想买入。
是不是单日题材只因消息刺激上涨，第二天容易冲高回落，需要公告或行业逻辑确认。
是否和持仓重复如果你已有同主题重仓，新买会放大组合风险。
止损点在哪里买之前先定失效条件，例如跌破 20 日线或成交额快速萎缩。

优化后的评分逻辑

Institutional score
universe = all_a_share_spot()
  .exclude(ST, delisting, low_price)
  .where(amount >= 3e8)

alpha_score =
  20/60日趋势与突破质量          # 不是越涨越好，过热会扣分
  + 量能确认                     # 放量但不过度拥挤
  + 价格相对均线结构             # 2-8周持仓周期

liquidity_capacity_score =
  amount_percentile              # 全市场成交额分位
  + capacity_band                # 成交容量是否能承载进出

fundamental_quality_score =
  ROE + 净利增速 + 收入增速
  + 毛利率 + 经营现金流质量
  - 高负债惩罚

valuation_sanity_score =
  PE_TTM + PB + PS_TTM + 股息率
  # 好公司也要避免估值过热

risk_control_score =
  波动率 + 回撤控制
  + 可交易性                     # 涨停/跌停/弱收盘扣分
  + 新股与杠杆风险

raw_institutional_score =
  0.30 * alpha_score
  + 0.22 * fundamental_quality_score
  + 0.14 * valuation_sanity_score
  + 0.19 * liquidity_capacity_score
  + 0.15 * risk_control_score
  - crowding_penalty

final_score =
  raw_institutional_score + 全市场分位校准
  - gate_penalty_score
  # 避免不同市场环境下分数整体偏低

action = "buy" only if:
  final_score >= 网页买入阈值
  and alpha_score >= 62
  and liquidity_capacity_score >= 55
  and risk_control_score >= 55
  and data_completeness >= 55%
  and 网页涨幅/收盘位置/振幅门禁全部通过

final_pool = rank(final_score)
  .cap_by_board()
  .with_reason()
  .with_risk_flags()
  .top(30)

为什么这样优化

Institutional habits
问题机构常见处理本系统改动
涨停股霸榜但买不到把可交易性和冲击成本纳入模型。tradability_score 接近涨停会降权，硬板只进入观察。
只看涨幅容易追高把收益信号和风险信号分开建模。momentum_sweet_spot 只奖励适度强势，过热由 crowding_penalty 扣分。
高波动票胜率不稳定用波动、振幅、流动性做风险门禁。risk_control_score 低于门槛不能标记为核心候选。
同一板块挤满候选池组合层做行业/风格暴露约束。当前先做板块数量上限，避免主板、创业板或科创板单边霸榜。
因子可能只在某段行情有效长期用 IC/RankIC、分组收益和 walk-forward 验证。下一步把评分拆解接入因子诊断，保留有效因子、降低失效因子权重。
