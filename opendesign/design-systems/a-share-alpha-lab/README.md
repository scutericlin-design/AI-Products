# A-Share Alpha Lab

Reusable design system for a professional A-share AI investment model workstation.

## Sources Consulted

- User brief: personal professional investor, 2-8 week holding period, high-elasticity growth, AI trading signal generation, full research workflow.
- Public data-source research:
  - Ricequant RQData documentation: A-share, macro, alternative data, factor research, optimizer, attribution modules.
  - AKShare stock data documentation: A-share quotes, financial statements, announcements, capital flow, hotness, concepts, sectors, technical indicators.
  - TuShare and JoinQuant official pages were checked, but their documentation pages are JavaScript or login-heavy in the browser context.

## Files

- `tokens/colors_and_type.css`: Color, typography, spacing, and state tokens.
- `brand/voice-and-tone.md`: Copy and tone rules.
- `SKILL.md`: Portable design-system marker.

## Design Direction

The interface should feel like a research terminal rebuilt for AI: compact, fast, explicit about uncertainty, and rich in diagnostics. It avoids generic dark-blue financial dashboards by using ink-black neutrals, cold paper surfaces, grid lines, acid green signal accents, and red risk accents.
