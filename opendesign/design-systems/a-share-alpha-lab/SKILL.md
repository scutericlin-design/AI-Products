# A-Share Alpha Lab Design System

Use this system for dense, professional investment research tools focused on China A-share equity selection, AI-assisted signal generation, multi-factor scoring, and risk-controlled portfolio construction.

## Character

- Tone: clinical, decisive, institutional.
- Audience: professional individual investors who expect quant detail without enterprise clutter.
- Visual principle: high information density, clear hierarchy, low ornament.
- Copy principle: speak in research conclusions, confidence levels, and explicit assumptions.

## UI Rules

- Prefer tables, rails, segmented controls, small multiples, and status chips.
- Use compact panels only for repeated data modules; avoid nested cards.
- Signal states should be visual before verbal: long, watch, reduce, blocked.
- Always pair model outputs with explainability: top factors, data freshness, risk reason, and override path.
- Use monospace for metrics, tickers, pseudocode, table schemas, and model diagnostics.

## Caution

This system is for research and prototype design. It must not present outputs as guaranteed returns or personalized financial advice.
