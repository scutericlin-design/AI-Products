# Stock Alpha 独立前瞻模拟盘

本版本借鉴公开多因子研究方法，不是私募专有模型，不承诺盈利，也没有证明是最优策略。历史研究命令与原策略不改动；新增实时模块仅进行模拟交易，不连接券商。

## 对照设计

| 账本 | 初始虚拟资金 | 策略 | 成交通知 |
|---|---:|---|---|
| A_baseline | 1,000,000元 | 冻结原始选股规则 | 不推送 |
| B_enhanced | 1,000,000元 | 质量35%、增长25%、估值20%、动量20% | 不推送 |
| C_ai | 1,000,000元 | B规则加有证据的AI机会选择 | 飞书模拟成交通知 |

A/B是比较账本，不是额外实投资金。所有账本使用相同行情、费用和真实股数模拟约束。新增统一8%成本硬止损，因此A的执行方式不等于旧的复权单位研究回放。

B在行业样本足够时使用行业内排名；ROIC、经营现金流收入比和利润增长等扩展指标覆盖率达到80%才启用，否则明确回退到既有财务指标。不是行业中性组合。

C的AI选择最多3个有有效正向数字证据的候选，正向主动配置最多为净资产20%，包含在总仓80%、单股8%、最多12只的共同上限内，不是额外加杠杆。保留相关性约束。无证据可以不调整，不强迫使用全部额度。

## 数据与调度

- 全部按北京时间和交易所交易日历运行。连续竞价期间每2分钟检查执行，避开午休、周末、节假日和收盘集合竞价。
- 工作日08:50准备已完成交易日的数据；每5个交易日选股再平衡，保留排名缓冲及1%净值调仓差额门槛。AI在再平衡时评估，不是实时新闻抓取器。
- 本期前瞻实验冻结最近研究股票池160只，使用TuShare财务、日线、复权因子、交易日历、涨跌停价和分红信息。财务按公告时间严格滞后使用。
- 中转实时行情端点本次返回空数据，使用独立Sina报价备份。报价须有供应商时间戳、同日且不超过120秒；不能把日线收盘价当实时成交价。
- 业绩快报接口本次报错，不启用；使用可用的业绩预告和财务报告事件。同比增长不等于超预期，AI不得虚构一致预期。
- 每日17:30核对收盘估值并备份自己的SQLite，保留14份；数据迟到时记录阻断，不能伪造收盘数据。

## AI权限

DeepSeek优先，MiniMax次选，StepFun第三；全部失败后回到本模块的确定性增强规则，并在成交记录和推送标记AI降级。下次再平衡重新尝试正常链路。无有效事件时不消耗模型调用。

AI输入、结果、事件引用与配置版本留档；每日调用预算和超时限制生效。AI不能修改代码、提高仓位上限、重置账户或放宽止损。当前没有训练预测模型，也没有自动参数升级入口。

## 模拟执行与限制

- T+1可卖数量、主板100股买入单位、科创板最低200股、现金和持仓上限、涨跌停缓冲、买卖盘口及成交量参与率检查。
- 佣金每边万五、每笔最低5元；卖出印花税万五；模拟滑点每边10个基点。费用是实验假设，不代表券商实际报价。
- 8%止损不是最大亏损保证，T+1、跳空、跌停均可能扩大损失。
- 公司行动尚无完整自动权益入账。发现除权分红或无法核对时冻结相关执行并标记估值待核对，不把机械除权记成正常盈亏。
- 部分成交后同计划同股票不会反复补单，剩余目标可能等下一次再平衡；不是完整订单簿撮合或可保证成交的实盘系统。
- C成交与推送出站记录同事务入库；网络失败重试，极端响应丢失可能重复通知，消息包含成交编号可核对。
- 无交易不发送选股观察消息。三个账户不互相调资金，旧股票、ETF、QGARP及热点龙头的账户和调度不变。

## 运维

独立云端目录 `/opt/chixiao-stock-alpha`，Compose项目 `stock-alpha-isolated`；无新公网端口。仅自己的 `/runtime` 可写，研究种子及独立密钥只读挂载。数据库丢失或损坏会阻断，不自动重新生成100万元。

```bash
docker compose -p stock-alpha-isolated -f /opt/chixiao-stock-alpha/docker-compose.yml exec stock-alpha-paper python -m stock_alpha.live status
docker compose -p stock-alpha-isolated -f /opt/chixiao-stock-alpha/docker-compose.yml logs --tail 50 stock-alpha-paper
```

`runtime/summary.json`、`health.json`、`plans/`、`paper.sqlite`分别保存账户汇总、状态、决策证据和独立账本。当前未接入旧dashboard。

上线仅代表开始前瞻实验。应比较扣费收益、回撤、换手、数据阻断、AI相对B的增量贡献及成本压力表现；至少跨多个再平衡周期观察。不能以几笔赚钱交易自动替换旧主策略，也不能把LLM当前知识用于历史回放后声称无未来信息。
